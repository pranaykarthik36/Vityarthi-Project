# Cricket Simulator – Python Project

## Overview
The **Cricket Simulator** is an interactive Python-based game that simulates a virtual cricket match between the user and the computer.

Users can choose their teams, perform a toss, play overs by entering numbers, score runs, take wickets, and finally view the match result.

This project is developed as part of the **VIT – Build Your Own Project (BYOP)** requirement.

## Features
- Team Selection
- Toss Simulation
- Over-by-Over Match Play
- Two Innings Structure
- Optional MySQL Database Storage

## Technologies Used
- Python 3
- random module
- mysql.connector (optional)

## How to Run
```
python cricket_simulator.py
```
