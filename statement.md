# Project Statement – Cricket Simulator

## 1. Problem Statement
A simple, text-based cricket simulation game is required to demonstrate Python programming concepts.

## 2. Scope of the Project
Includes:
- Team selection
- Toss simulation
- Match simulation with overs
- Run and wicket logic
- Result calculation

## 3. Target Users
- Python learners
- Cricket enthusiasts
- Students completing BYOP projects

## 4. High-Level Features
- Fully interactive CLI-based cricket match
- Ball-by-ball simulation
- Randomized computer batting/bowling
- Two innings and match result
